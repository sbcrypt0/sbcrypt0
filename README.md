# Hi, I'm Ethan

I'm a **web developer** and the founder of **[CipherWorx](https://cipherworx.co.uk)**, a small web agency building websites for small businesses in the UK. I'm self-taught and still early on: I'm now learning the back end (**Python**, **Flask** and **SQL**) and building small AI tools along the way.
I'm looking for **employment** where I can learn properly, with structure and mentorship, while doing useful work.

## Featured Projects

**[Cipher](https://github.com/sbcrypt0/cipher-live-listener)**: an AI that listens to a live meetup conversation and only speaks up when it has something worth adding. Live speech-to-text (ElevenLabs) feeds a decision step built on Claude, and anyone in the room can ask it a question by name. Built for the Steel City AI community in Sheffield.

**[Scriptorium](https://github.com/sbcrypt0/scriptorium)**: a local-first "second brain" in a single HTML file, with linked notes, a knowledge graph, spaced-repetition flashcards, a journal and optional AI synthesis. [Live demo](https://sbcrypt0.github.io/scriptorium/)
